# Contributing to Awesome TTRPG Tools

Thanks for wanting to contribute! 🎲

## How to add a tool

1. Fork this repository
2. Add your tool to the appropriate section in `README.md`
3. Follow this format:
    
    -> Tool Name — Short, clear description of what it does.

4. Make sure the tool is:
   - Relevant to tabletop RPGs
   - Currently maintained and available
   - Not already listed
5. Submit a Pull Request

## Guidelines

- Keep descriptions short (one sentence)
- Add tools in alphabetical order within their section
- If a tool fits multiple categories, pick the most relevant one
- Don't add affiliate links

## Suggesting a new category

Open an issue with the suggested category name and at least 3 tools that would fit in it.

Thanks for helping make this list awesome! 🙌
